impacto: nada_mudou
secao: corrigido
titulo: Desmarcar uma conversa como exemplo para a IA tira o que o agente já tinha aprendido dela
---

Quando uma conversa deixava de ser exemplo para a IA, o sistema parava de usá-la nos próximos aprendizados, mas os trechos que o agente já tinha guardado dela continuavam disponíveis para ele consultar. Agora, ao desmarcar, esses trechos são apagados na hora. Os de outras conversas não mudam. Se a conversa for marcada de novo, ela volta a ser aprendida no próximo lote.

Refs #3006.
